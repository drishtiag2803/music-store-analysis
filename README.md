Music Store Data Analysis Project

Objective
Analyze customer purchasing behavior and sales trends using SQL.

Tools Used
PostgreSQL

Analysis Performed
- Senior employee analysis
- Country-wise invoices
- Top customers
- Genre popularity
- Artist productivity
- Monthly revenue trend

Key Insights
- A small group of customers generates most revenue
- Certain cities produce higher sales
- Popular genres dominate purchases
- Top artists drive majority of sales
- Monthly revenue shows trends

Skills Demonstrated
SQL joins, aggregation, subqueries, filtering, grouping, analytical thinking.
